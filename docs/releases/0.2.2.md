# 0.2.2

This release adds lockscreen navigation-map ownership, status-cluster positioning,
a restrained icon family shared with hc-lite, and a soft right edge for swiped
notifications. Device rendering remains owner acceptance.

## Changed behavior and causes

- AMap walking/cycling map integration now has its own enabled-by-default switch.
  Previously its recommended scope exposed no independent control. Disabling it
  immediately releases the immersive map, queued overview, clock/veil owner and
  remote Surface; the ordinary navigation row and other live/music owners survive.
- The status cluster has a signed vertical dp offset. Zero preserves the recovered
  MiDuo baseline; the common lockscreen/AOD geometry applies the offset exactly once.
  The slider covers -24..24 dp in 1 dp steps; exact input permits -80..80 dp.
  Invalid/old backup fields do not reset the current choice. Other rail items do
  not move, and no live MiDuo coordinates are read.
- Native notification-stack measurement still reserves the right rail. Its hard
  edge became visible during right swipes after native list scrolling. A local
  GPU band now increases blur/fade within the right-swiping row's actual clipped
  vertical region. Without a positive swipe, drawing stays entirely native; during
  a swipe, pixels outside that narrow region replay unfiltered. Overlapping content
  or shadows within the same band are composited too. The native dispatch executes
  once, with no bitmap/readback, input interception or replacement of the OEM
  material effect. Keeping the stack dispatch also preserves its native child-Z
  ordering. Unknown contracts/software canvases retain native rendering. Nested
  MIUI backdrop sampling and GPU cost still need device acceptance; host tests do
  not prove the rendered result.
- Adaptive, round and themed vector icons share the orange HC-derived family.
  English resource omissions found by full lint are completed. Privileged status
  reads run only in injected SystemUI context and already handle permission errors;
  narrow lint annotations document this boundary without adding App permissions.

## Host verification

- 990 JVM tests in 160 suites passed, with no failures, errors or skips.
- New fixtures cover AMap availability/backup, status offset/density/transform
  idempotence, edge geometry/translation/actual clip and exactly-once failure paths.
- Full lint and signed optimized packaging are checked before archival. Local
  receipts record exact source/signing identity and equal retained/archive hashes.
- No installation, scope restart, whole-phone reboot, GUI or screenshot was used.

## Focused owner acceptance

1. Toggle AMap map off/on during navigation: only the immersive map changes;
   its ordinary notification/live entry remains usable.
2. Move the status-cluster offset, enter/leave AOD and restore zero: the cluster
   moves consistently without moving capsules or shortcut buttons.
3. Expand/scroll notifications and swipe one right: the right edge softens only
   at its clipped boundary, preserving material and normal swipe behavior. Other
   regions should remain unchanged; check shadow overlap near the boundary.
4. Inspect both launcher icons, including the system themed-icon mode.
