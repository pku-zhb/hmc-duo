# 0.2.12 valid clock-pose ownership

Includes [0.2.11](0.2.11.md) and pairs with Lite 0.1.9.

The 0.2.11 direct-AOD device test still failed. Keeping the failing scene asleep
exposed the missing contract: the page and resource were ready, but `held=true`
coexisted with a NaN start position and no committed lease. Each pre-draw therefore
skipped acquisition and fell back without submitting replacement time.

Clock capture, committed endpoints, cover rest and AOD poses now use complete
immutable snapshots. Failed measurement cannot publish a partial pose or poison a
valid same-domain endpoint. AOD latching and recovery use the same valid-pose and
actual-commit contract; an unchanged native value still permits a legitimate
commit. A completed endpoint from the same pass is preferred over remeasurement.
No background/material change, retry timer or guessed geometry is introduced.

The cold credential-to-AOD reproduction can be checked without repeated owner
authentication. Direct desktop-to-AOD remains a separate device acceptance case.
Host checks and installed results are recorded in the existing rolling document.
