# 0.2.9 native media-card lifecycle

Includes [0.2.8](0.2.8.md) and pairs with Lite 0.1.9.

Device testing found that changing display posture replaced the OEM media card
while the page button and guard still referenced the detached outer-screen card.
Tapping the visible inner card then reached the native app-launch/authentication
handler instead of cycling pages. Card and child identities now belong to native
header attachment, replacement and layout events. Consumers validate that binding
before using its controls. The former twelve delayed retries are removed.

Notification compaction now prevents artwork sampling regardless of a raw lyrics
or player request. Explicit lyrics enable/search uses the same complete page
transition as the player control, rather than changing half the page flags.

The source tests, optimized APK checks and installed device scenario results are
recorded separately. The one existing rolling acceptance document remains the
owner-facing record; numeric state observations are not pixel-level acceptance.
