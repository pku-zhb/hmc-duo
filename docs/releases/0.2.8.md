# 0.2.8 consolidated lockscreen presentation

Paired with Lite 0.1.9. This iteration implements the owner's clarified layout,
compact-player and background behavior and replaces competing update paths with
shared scene ownership. APK installation and scope reload are now authorized;
phone screenshots and full reboots remain avoided/prohibited respectively.

## Confirmed causes and changes

- Release optimization repackaged view classes, so namespace-based material
  registration rejected owned capsules and shortcut plates. Explicit type markers
  retain identity through R8; an actually repackaged test target covers the failure.
- Full-AOD backgrounds depended on clock phase/container visibility and used a
  separate 64/255 wash. Static presentation now uses native full-AOD state and the
  selected source/dimming. Closing artwork for notifications also releases all
  backdrop/sampling ownership; explicitly opening the page restores it.
- Wake previously refreshed consumers before publishing awake state. Ordinary
  ART/LYRICS selection also triggered a delayed re-layout/re-push. Input ordering
  is corrected, unnecessary composition rebuilds are removed and the existing
  background owner coordinates mesh/static handoffs from real presented frames.
- Clock draw completion re-entered the full pose writer. Transient missing geometry
  and per-frame unit/zero restoration could also give control back to native or
  overwrite the rail. The leaf now only publishes measurement, clock consumes one
  scene snapshot, caches are domain-checked and all property restoration is leased.
- Height now offers compact 75% and native 100%. The compact preset balances
  visible gaps without shrinking playback/seek input, and AOD budgets only its
  two visible rows. Old intermediate values normalize to the nearest preset.
- Inner widths are OEM-owned in every page. Single pages center in the full safe
  window; only the combined page translates the whole native column. Translation
  targets and last actual writes are distinct, with native writes observed even
  when keyguard eligibility ends.

See [presentation ownership](../../design/PRESENTATION_OWNERSHIP.md) and
[player metrics](../../design/PLAYER_HEIGHT.md). Lite separately repairs deferred
ordinary material selection and unified lit-keyguard recipes, while preserving
native AOD selection and independent animation opt-in.

## Host and device boundary

The consolidated JVM suite passes 1,083 tests in 172 suites with zero failures,
errors or skips; Debug lint and build pass. Final optimized source/signature/hash
verification follows the clean committed/pushed release workflow. Numeric phone
scenario results and any remaining manual visual checks are maintained in the
one existing rolling acceptance document, not duplicated here as visual acceptance.
