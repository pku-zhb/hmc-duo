# 0.2.5 final candidate

This is the final candidate for the current iteration. It includes every
[0.2.4 fix and focused acceptance item](0.2.4.md), including the correction for
last-lockscreen saving being blocked by a stale AMap readiness signal. The
previously archived 0.2.4 package and its record are retained unchanged.

## Added support entry

About → Support Duo now opens the maintainer-provided WeChat support image.
The PNG is retained unchanged in a raw resource and displayed with proportional
fit. Save image copies its original bytes into Pictures/hmc-duo through
MediaStore; it does not re-encode or crop the image. Publication occurs only after
the write completes, with an incomplete entry removed on failure. No broad
storage permission or external payment app launch is required. Alipay is not
shown because the owner has not supplied an asset for it.

The source asset SHA-256 is
`2f7e457d3151807161d10edf6cb4d11201fb8f572236494bb5ef3fc454ac3da3`.
Default, English and Chinese support text are kept aligned. No module preference,
backup field or hook protocol changes in this addition.

## Validation

The retained PNG matches the supplied file byte for byte. Resource identity and
references, source changes and version 0.2.5 / 205000 were checked. Final unified
tests, lint and release construction are performed on the committed release
source. The previous 0.2.4 host results are historical, not a claim about this
new package.

Alongside the inherited 0.2.4 list, check that About → Support Duo shows the
complete WeChat image and Save image creates a readable image in the gallery.
Actual photo-album saving and WeChat recognition remain owner-operated checks.
This source addition does not install, restart a scope or operate the phone UI.
