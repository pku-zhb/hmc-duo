# 0.2.3

- Cache positive SystemUI IDs per Resources owner, removing repeated resource-name
  resolution from right-rail pre-draw. Missing IDs are retried for late assets.
- Feather both notification edges symmetrically. Drag distance controls band width,
  never terminal opacity. Native Canvas dimensions and Z order are preserved; the
  old extra blur is removed. See design/NOTIFICATION_EDGE.md.
- AMap uses the selected clock destination. Navigation lock/AOD entry temporarily
  expands only its live card; original presentation is restored afterward, without
  changing saved defaults.
- Remote map replies and connections are generation-bound. Closing the map retires
  its SurfacePackage instead of retaining a prepared layer behind later materials.
  Reopening therefore requires remote rebinding and may take longer to load.
- Compact feature UI, separate offset slider/reset interaction and functional icons.

1000 host tests in 163 suites and full Debug lint pass. Optimized signed packaging
and clean pushed-source metadata are verified before archiving. The old build's
read-only CPU samples prove resource-lookup hotspots, but do not prove new phone
rendering or explain every first-entry stall. No phone UI, installation, scope
restart, or whole-phone reboot was used.

Focused acceptance: first-entry AOD/notification smoothness, both notification
swipe edges before/after scrolling, navigation clock/session/close-background, and
slider reset layout. The paired Lite/compat changes have separate validation.
